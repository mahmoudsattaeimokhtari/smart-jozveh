# جزوه‌نگار هوشمند

یک اپلیکیشن کاملاً استاتیک و Client-Side Only برای تبدیل صوت کلاس به متن وفادار، مجموعه سؤال‌ها و جزوهٔ موضوع‌بندی‌شده.

## پردازش دسته‌ای متن و NotebookLM

حالت پیش‌فرض «متن جلسات و بسته NotebookLM» است. فایل‌های `.md`، `.txt` یا `.json` را با انتخاب چند فایل یا یک پوشه وارد کنید. UTF-8 و UTF-16 با BOM پشتیبانی می‌شوند. مثال نام: `Session_01_Transcript.md`؛ هدرهایی مثل «جلسه ۱۲» و «جلسه دوم» نیز قابل تشخیص‌اند. چند فایلِ یک جلسه در یک ورودی با حفظ ترتیب نام فایل ادغام می‌شوند؛ جلسات بر اساس شماره مرتب می‌شوند.

JSON می‌تواند `transcript` یا `text` متنی، یا آرایهٔ `paragraphs`، `segments` یا `transcriptParagraphs` داشته باشد. در آرایه، هر بند شامل `text` و در صورت وجود `startSec`، `start` یا `originalStartSec` است. `sessionNumber` و `title` نیز قابل استفاده‌اند. فایل بدون شماره یا با ساختار نامعتبر در گزارش ورودی مشخص می‌شود.

پس از ذخیره کلید Gemini در کادر بالای صفحه، «پردازش / ادامه جلسات» را بزنید. مدل `gemini-3.5-flash-lite` فقط متن دریافت می‌کند. خروجی هر بخش پس از کنترل ارجاع‌ها و ساختار ذخیره می‌شود؛ پس از رفرش، بخش‌های کامل دوباره به API فرستاده نمی‌شوند.

برای هر جلسه سه فایل آماده می‌شود:

1. `Transcript_and_Classic.docx`: متن اصلی عین ورودی، سپس جزوه کلاسیک؛ تغییر متن اصلی محدود به شکل ارقام فارسی در خروجی Word است.
2. `Questions.docx`: سؤال‌های واقعی کلاس با شاهد پاسخ، و سؤال‌های تألیفی چهارگزینه‌ای با پاسخ تشریحی، در دو بخش مجزا.
3. `Classic.docx`: جزوه موضوعی با ارجاع به برچسب زمانی واقعی متن و برجسته‌سازی نکات امتحانی.

تمام Wordها RTL، فونت فارسی متن B Nazanin، تیتر بولد B Zar، عبارت لاتین Times New Roman و فاصله خطوط Single دارند. فونت‌های نام‌برده باید در دستگاهی که Word را باز می‌کند موجود باشند. نسخهٔ TXT دست‌نخوردهٔ متن اصلی و نسخه‌های Markdown خروجی نیز در ZIP قرار می‌گیرند.

ساخت خودکار PDF برای گروه‌های کامل ۱–۵، ۶–۱۰ و... قابل تنظیم است. PDF شامل صفحه عنوان، فهرست، متن اصلی، جزوه و سؤال‌ها است؛ فونت آزاد فارسی وزیرمتن درون فایل تعبیه شده و نگاشت Unicode برای استخراج متن فارسی تصحیح می‌شود. برای گروه ناقص، دکمه PDF فقط جلسات آماده را با ذکر شماره‌های واقعی بسته‌بندی می‌کند. هیچ زمان یا جلسهٔ گمشده‌ای ساخته نمی‌شود.

خروجی‌ها و PDFها در IndexedDB همین مرورگر حفظ می‌شوند. اگر مرورگر دانلودهای خودکار پیاپی را محدود کند، فایل آماده از دکمه PDF یا ZIP دوباره قابل دریافت است. «شروع دسته جدید» دسته قبلی را بایگانی می‌کند. کلید API وارد IndexedDB دسته یا فایل‌های خروجی نمی‌شود.

## معماری و حریم خصوصی

- کلید شخصی Gemini از رابط برنامه دریافت و فقط در `localStorage` همان مرورگر نگه‌داری می‌شود.
- کلید در سورس، متغیرهای GitHub Actions یا خروجی `dist` قرار نمی‌گیرد.
- صوت بدون File API و بدون آپلود resumable، مستقیماً به‌شکل `inlineData` در درخواست `generateContent` مدل `gemini-3.5-flash-lite` ارسال می‌شود.
- فایل‌های صوتی، وضعیت صف و نتایج پردازش در IndexedDB همان مرورگر ذخیره می‌شوند.
- هر ۳۰ دقیقه صوت به یک فایل MP3 تک‌کانالهٔ 16kHz و 24kbps با حجم حدود ۵٫۴ مگابایت تبدیل می‌شود. رمزگذاری در Worker انجام و فایل آماده در IndexedDB ذخیره می‌شود.
- متن و جزوه با `streamGenerateContent` به‌صورت SSE دریافت می‌شوند. سقف انتظار دریافت هدر و سکون جریان ۱۸۰ ثانیه است؛ کل پردازش صوت حداکثر ۲۰ دقیقه و ساخت جزوه حداکثر ۱۰ دقیقه زمان دارد. دریافت هر بخش پاسخ در صفحه نمایش داده می‌شود.
- اندازهٔ کل JSON پیش از ارسال کنترل می‌شود و زیر ۱۹ مگابایت می‌ماند. فایل و متن آماده برای ادامهٔ پردازش مجدد استفاده می‌شوند.
- هیچ سرور Node/Express یا اندپوینت `/api/config` در نسخهٔ وب وجود ندارد.

پاک‌کردن داده‌های سایت در مرورگر، کلید و اطلاعات ذخیره‌شدهٔ محلی را حذف می‌کند. `localStorage` رمزگذاری مستقل از مرورگر نیست؛ این برنامه هیچ اسکریپت ثالثی اجرا نمی‌کند و Content Security Policy دسترسی اسکریپت‌ها و اتصال‌های شبکه را محدود می‌کند.

## توسعه و بررسی

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
```

تنظیم `base: './'` در Vite باعث می‌شود محتوای `dist` زیر مسیر مخزن GitHub Pages نیز کار کند.

## انتشار

هر Push به شاخهٔ `main` گردش‌کار `.github/workflows/deploy-pages.yml` را اجرا می‌کند. این گردش‌کار نصب تمیز، بررسی TypeScript، بیلد و انتشار `dist` روی GitHub Pages را انجام می‌دهد.

پس از بازشدن آدرس HTTPS:

1. VPN داخلی Firefox را برای صفحه روی یک کشور پشتیبانی‌شده فعال کنید.
2. کلید شخصی Gemini را در کادر بالای صفحه وارد و ذخیره کنید.
3. «تست مستقیم از مرورگر» را اجرا کنید.
4. پس از اتصال موفق، فایل صوتی را انتخاب و پردازش را آغاز کنید.
